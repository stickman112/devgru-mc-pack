# DEVGRU MC

DEVGRU MC is a Minecraft 1.20.1 Forge modpack.

## Players

Server address: `forge.devgru-mc.org`

Setup guide: see the [wiki](https://github.com/stickman112/devgru-mc-pack/wiki), starting with [Setup: Prism Launcher](https://github.com/stickman112/devgru-mc-pack/wiki/Setup-Prism).

CurseForge support is in progress; Prism Launcher is recommended.

## Maintainers

See [CLAUDE.md](CLAUDE.md) for working conventions: the side scheme, the version-pinning policy, how the server installs, and the deliberate sidecar exclusions.

The pack manifest is served at https://stickman112.github.io/devgru-mc-pack/pack.toml (the URL the server and the Prism pre-launch hook install from).
