# DEVGRU MC Pack

Canonical [packwiz](https://packwiz.infra.link/) source of truth for the DEVGRU MC modpack (Minecraft 1.20.1, Forge 47.4.10).

This repo is the single source the Dedic8 server and all player clients install from. It is served over GitHub Pages; the pack manifest lives at:

> https://stickman112.github.io/devgru-mc-pack/pack.toml

## Players

Onboarding guides are coming (Prism Launcher recommended, CurseForge launcher supported). A GitHub wiki with full install and connection docs is planned. For now, ask in Discord for setup help.

Server address: `forge.devgru-mc.org:25567`

## Maintainers

See [CLAUDE.md](CLAUDE.md) for working conventions: the client/server/both side scheme, the version-pinning policy, how the server installs (`-s server`), and the deliberate exclusions (the TACZ MW Gun Pack content pack and Jake's WorldGuard are manual server-side sidecars, not in this pack).
